# Developer Portfolio (React + Vite)
    npm install
    npm run dev      # local dev server
    npm run build    # production build in /dist

All content lives in `src/data/portfolio.js` (name, projects, skills, services, experience,
testimonials, contact, socials, background code snippets). Put images in `public/images/`
and reference them as `/images/your-file.png`. Colors and fonts are CSS variables at the top of `src/styles.css`.
